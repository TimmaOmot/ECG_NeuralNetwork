# Explicit V1 label mapping

V1 will treat `{N, L, R, e, j}` as Normal and `{A, a, J, S, V, E, F}` as Abnormal. Paced, fusion-paced, and unclassifiable symbols (`/`, `f`, `Q`), plus non-beat annotations, are excluded rather than silently folded into Abnormal; the five-class V2 will use the same documented superclass convention.
